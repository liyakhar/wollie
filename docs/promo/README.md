# Wollie promo video
- `wollie-promo-v2.mp4`: 33 s, 1920x1080, 60 fps, with Cartesia voiceover (voice Brandon), Mixkit music and effects. First version: `wollie-promo.mp4` (20 s, no voice).
- `film2/film2.html` is the film (every frame is computed from time). Render: `node film2/render2.mjs` then mix the audio in ffmpeg. Fonts are in the same folder.
- `voiceover/` holds the script and the timing file. `CREDITS.md` lists the music sources.
- `x-motion-prompts.md` are the X posts with motion prompts that inspired it.
- Numbers on screen are sample numbers, not real user data.
