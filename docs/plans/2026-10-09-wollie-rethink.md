# Wollie rethink (2026-10-09)

Liya's brief: drop "safe to spend". Wollie is for clear spending, monthly budgets,
automatic monthly saving (e.g. "House, €1,000 every month"), and couples who
link different banks. A person sets it up once, then checks daily:
"Am I within budget? Did I save this month?"

## The three daily questions → Home
1. **How much did I spend this month?** Spent card with a pace chart
   (spending line vs. even-pace budget line), "€X left · N days to go", status
   pill: On track / Spending fast / Over budget.
2. **Did I save this month?** Savings card: "€1,000 of €1,200 set aside", one
   chip per goal (moved / waiting for payday / to move).
3. **Anything wrong?** One attention row per over-budget category.
Then: top categories strip, next bills.

## Tabs
Home · Spending · Budgets · Savings (Goals is renamed Savings; goals stay goals).

- **Spending**: month switcher, total + change vs last month, category ring
  chart, category list (share, change vs last month), 6-month trend bars,
  Transactions view with search and re-categorise (kept).
- **Budgets**: summary "€X left of €Y", each category bar with a pace tick
  ("where you should be today"), spending with no budget shown as its own row.
- **Savings**: total saved, this month's plan, one card per goal with monthly
  amount, progress, "at this pace: <date>", last 6 months as dots
  (saved / skipped / missed), Save vs Invest kinds.

## Automatic saving (read-only bank, so Wollie cannot move money)
- Payday starts the month (detected salary day, or a set day, or the 1st).
- After payday, money moved out to savings (Savings / Transfer category,
  outgoing) is matched to goals in order and ticked automatically.
- Manual "mark as saved" / "skip" stays as a fallback.
- Push on payday: "Payday. Set aside €1,200 for your goals."

## Partners
- Household: invite by email; each person keeps their own login and connects
  their own bank. Home shows both avatars; Spending can filter All / You /
  Partner by account owner.

## First run
Checklist with real progress: connect bank → set budgets (suggested from
history) → add a savings goal → invite partner (optional).
